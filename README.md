# Lucy Epoxy Studio (HTML)

To repozytorium zawiera statyczną wersję strony opartą o pliki HTML/CSS/JS (bez Astro).

## Główne pliki strony

- `LucyEpoxyStudio.html` – strona główna (PL)
- `LucyEpoxyStudio-en.html` – strona główna (EN)
- `LucyEpoxyStudio-de.html` – strona główna (DE)
- `contact.html` – kontakt
- `zamow-project.html` – zamówienie
- `realizacje.html` – realizacje
- `projekty.html` – projekty

## Uruchomienie lokalne

To strona statyczna – wystarczy otworzyć pliki `.html` w przeglądarce.

Opcjonalnie możesz użyć prostego serwera lokalnego:

```bash
python -m http.server 8080
```

Następnie otwórz:

- `http://localhost:8080/LucyEpoxyStudio.html`

## Deploy

Możesz wdrożyć stronę jako static site na dowolnym hostingu (np. Vercel/Netlify/GitHub Pages).
